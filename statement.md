# Weather App

## 📌Problem Statement

People often need quick access to current weather information
for planning travel and daily activities.

The Weather App provides a simple way to check current weather
conditions for any city using Python and weather APIs.

## 📌Scope of Project

The application allows users to enter a city name and view:

- Temperature
- Humidity
- Weather condition

The project demonstrates Python GUI programming,
API integration, JSON processing and exception handling.

## 📌Target Users

- Students
- Travelers
- General users
- People planning outdoor activities

## 📌High Level Features

1. City Search
2. Weather Data Retrieval
3. Weather Information Display
4. Error Handling
